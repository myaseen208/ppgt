# Package Comparison Helpers

## 1 Abstract

The functions
[`compare_all_designs()`](https://myaseen208.github.io/ppgt/reference/compare_all_designs.md)
and
[`compare_all_designs_honest()`](https://myaseen208.github.io/ppgt/reference/compare_all_designs_honest.md)
are package comparison helpers. They summarize matrices returned by
package constructors and attach package-specific labels. Their outputs
should not be read as direct literature results.

## 3 Reading The Metrics

For a design matrix \\\mathbf{M} \in \\0,1\\^{J \times N}\\, the helpers
summarize:

- \\J\\: number of pools
- \\N\\: number of individuals
- \\J/N\\: tests per individual in the design summary
- \\\lambda\_{\max} = \max_i \|\mathcal{J}\_i\|\\: maximum column weight

These summaries are intentionally structural. They compare the realized
matrix dimensions, row/column weights, and package reporting labels for
the generated design objects. They do not prove optimality, establish a
universal ranking, or replace family-specific theoretical guarantees.

## 5 Interpreting The Labels

The package prints labels such as `Configuration`, `Error_Correction`,
and the entries in `summary`. Those labels are package-specific
reporting choices for these helpers. They are useful for package
navigation, but they are not formal paper-backed guarantees.
