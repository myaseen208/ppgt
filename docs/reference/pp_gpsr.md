# GPSR Compressed Sensing Algorithm

Solves the \\\ell_1\\-regularized least squares problem for scoring
candidate samples when COMP produces too many candidates.

## Usage

``` r
pp_gpsr(
  A,
  y,
  tau = NULL,
  max_iter = 500L,
  tol = 1e-05,
  continuation_steps = 5L,
  first_tau_factor = 0.8
)
```

## Arguments

- A:

  Numeric design matrix with dimensions \\J \times N\\. In the decoding
  pipeline it is typically the submatrix of positive pools by candidate
  individuals, but any numeric matrix is allowed.

- y:

  Numeric vector of length \\J\\ containing the observed response
  associated with `A`. In the decoding pipeline this is usually a vector
  of normalized pool intensities or binary positive-pool indicators.

- tau:

  Numeric non-negative regularization scalar or `NULL`. When `NULL`
  (default), \\\tau\\ is computed from the data as \$\$\tau = 0.005
  \cdot \max\|\mathbf{A}^T \mathbf{y}\|\$\$ using the package's default
  GPSR scaling. Supply a positive numeric value to override the
  data-adaptive default. Larger values promote sparser solutions.

- max_iter:

  Integer scalar giving the maximum number of projected-gradient
  iterations. The default is `500L`.

- tol:

  Numeric scalar giving the convergence tolerance for the relative
  change in objective value. The default is `1e-5`. Convergence is
  declared when \\\|F(\mathbf{z}\_{\text{new}}) - F(\mathbf{z})\| /
  \max(1, \|F(\mathbf{z})\|) \< \texttt{tol}\\.

- continuation_steps:

  Integer scalar giving the number of warm-start continuation steps
  before the main loop. The default is `5L`.

- first_tau_factor:

  Numeric scalar giving the scale factor that determines the starting
  regularization in the continuation schedule. The default is `0.8`. It
  sets the continuation starting value through \\\tau\_{\text{start}} =
  \texttt{first\\tau\\factor} \cdot \max\|\mathbf{A}^T\mathbf{y}\|\\.

## Value

A list with components:

- x:

  Numeric vector; the estimated sparse solution

- iterations:

  Integer; number of iterations performed

- converged:

  Logical; TRUE if converged before max_iter

## Details

GPSR (Gradient Projection for Sparse Reconstruction) solves the convex
optimization problem \$\$ \min\_{\mathbf{x} \geq 0}
\frac{1}{2}\\\mathbf{y} - \mathbf{A}\mathbf{x}\\\_2^2 +
\tau\\\mathbf{x}\\\_1. \$\$ The \\\ell_1\\ penalty promotes sparse
solutions while the non-negativity constraint keeps the candidate scores
interpretable as non-negative weights.

## Algorithm

The implementation follows a GPSR-BB style projected-gradient scheme
with a short continuation warm start. Let \\F\_\tau(\mathbf{z}) =
\frac{1}{2}\\\mathbf{A}\mathbf{z} - \mathbf{y}\\\_2^2 + \tau
\mathbf{1}^T\mathbf{z}\\ with gradient \\\nabla F\_\tau(\mathbf{z}) =
\mathbf{A}^T\mathbf{A}\mathbf{z} - \mathbf{A}^T\mathbf{y} +
\tau\mathbf{1}\\. Before the main loop, the algorithm applies
`continuation_steps` projected-gradient updates at geometrically
decreasing regularization values from \$\$ \tau\_{\text{start}} =
\texttt{first\\tau\\factor} \cdot \max\|\mathbf{A}^T\mathbf{y}\| \$\$
down to the target \\\tau\\. The main loop then alternates gradient
evaluation, projection onto the non-negative orthant, backtracking line
search, and a Barzilai-Borwein step-size update. Convergence is declared
when \$\$ \frac{\|F\_\tau(\mathbf{z}\_{k+1}) -
F\_\tau(\mathbf{z}\_k)\|}{ \max(1, \|F\_\tau(\mathbf{z}\_k)\|) } \<
\texttt{tol}. \$\$

## Role in Decoding

When COMP produces more candidates than \\k\_{\max}\\, GPSR assigns
continuous scores to those candidates. Larger scores indicate stronger
support for inclusion in a sparse positive set, but the scores
themselves are not final binary calls.
