# Find Valid Polynomial Pools Configurations

Enumerate PP parameter combinations that satisfy user-supplied design
constraints, so that candidate pooling matrices can be planned before
calling
[`pp_matrix`](https://myaseen208.github.io/ppgt/reference/pp_matrix.md).

## Usage

``` r
pp_design(
  N_min = 50,
  N_max = 1000,
  M_max = 500,
  k_min = 2,
  pool_size_max = 500
)
```

## Arguments

- N_min:

  Integer scalar giving the minimum allowed number of individuals \\N\\.
  Only PP configurations with \\q^d \ge N\_{\min}\\ are retained.

- N_max:

  Integer scalar giving the maximum allowed number of individuals \\N\\.
  Only PP configurations with \\q^d \le N\_{\max}\\ are retained.

- M_max:

  Integer scalar giving the maximum allowed number of pools \\J\\. The
  default is `500`.

- k_min:

  Integer scalar giving the minimum required COMP detection limit
  \\k\_{\max} = \lfloor (n_l - 1)/(d - 1) \rfloor\\. The default is `2`.

- pool_size_max:

  Integer scalar giving the maximum allowable canonical pool size
  \\q^{d-1}\\. The default is `500`.

## Value

A data frame with one row per retained PP configuration and columns:

- q:

  Integer; Galois Field order (prime power)

- d:

  Integer; dimension

- nl:

  Integer; number of layers

- N:

  Integer; maximum samples (\\q^d\\)

- M:

  Integer; legacy display alias for the number of pools \\J = n_l q\\

- pool_size:

  Integer; samples per pool (\\q^{d-1}\\)

- k_max:

  Integer; detection limit

- compression:

  Numeric; display alias for the compression ratio \\N/J\\

The rows are sorted by decreasing `compression` and then by increasing
`pool_size`. The function returns `NULL` if no configuration satisfies
the supplied constraints.

## Details

For each candidate PP parameter tuple \\(q, d, n_l)\\, the associated
full design has \$\$N = q^d, \qquad J = n_l q, \qquad n_j = q^{d-1},
\qquad w_i = n_l.\$\$ The COMP exact-decoding guarantee for PP designs
is governed by \$\$k\_{\max} = \left\lfloor \frac{n_l - 1}{d - 1}
\right\rfloor.\$\$ This function searches a finite library of supported
prime powers \\q\\ and dimensions \\d \in \\2,3,4\\\\, filters the
resulting tuples by the user constraints, and reports the compression
factor \$\$\frac{N}{J}.\$\$ The output is intended for planning rather
than for direct matrix generation; once a row is selected,
[`pp_matrix`](https://myaseen208.github.io/ppgt/reference/pp_matrix.md)
can be used to construct the corresponding \\\mathbf{M} \in \\0,1\\^{J
\times N}\\.

## Relationship to pp_matrix and pp_verify

- **`pp_design`**: Finds valid parameter combinations (planning)

- **[`pp_matrix`](https://myaseen208.github.io/ppgt/reference/pp_matrix.md)**:
  Generates the actual pooling matrix (construction)

- **[`pp_verify`](https://myaseen208.github.io/ppgt/reference/pp_verify.md)**:
  Checks properties of a generated matrix (validation)

Typical workflow:

    # 1. Find suitable configurations
    configs <- pp_design(N_min = 300, N_max = 500)

    # 2. Choose one and generate matrix
    M <- pp_matrix(q = 8, d = 3, nl = 6, N = 384)

    # 3. Verify the matrix
    pp_verify(M)

## Generalization Rules

The PP algorithm generalizes to any \\(q, d, n_l)\\ where:

1.  \\q\\ is a **prime power**: 2, 3, 4, 5, 7, 8, 9, 11, 13, 16, 25, 27,
    ...

2.  \\d \geq 2\\ (dimension)

3.  \\1 \leq n_l \leq q + 1\\ (number of layers)

## What You CANNOT Choose Arbitrarily

|                           |                                                 |
|---------------------------|-------------------------------------------------|
| **Constraint**            | **Why**                                         |
| \\q\\ must be prime power | Galois Fields only exist for prime power orders |
| \\M = n_l \times q\\      | Each layer contributes exactly \\q\\ pools      |
| Pool size = \\q^{d-1}\\   | Fixed by the polynomial structure               |

## Design Selection Guide

|             |                 |           |                 |
|-------------|-----------------|-----------|-----------------|
| **Samples** | **Recommended** | **Pools** | **Compression** |
| ~64         | q=4, d=3, nl=5  | 20        | 3.2x            |
| ~384        | q=8, d=3, nl=6  | 48        | 8x              |
| ~729        | q=9, d=3, nl=7  | 63        | 11.6x           |
| ~4096       | q=16, d=3, nl=9 | 144       | 28x             |
