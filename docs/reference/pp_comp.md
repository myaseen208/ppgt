# COMP Decoding Algorithm

Decodes pooled test results using the Combinatorial Orthogonal Matching
Pursuit (COMP) algorithm, which guarantees zero false negatives.

## Usage

``` r
pp_comp(M, y, ct_threshold = 40)
```

## Arguments

- M:

  Binary pooling matrix \\\mathbf{M} \in \\0,1\\^{J \times N}\\. It may
  be dense or sparse. Row \\j\\ corresponds to pool \\\mathcal{P}\_j\\
  and column \\i\\ corresponds to individual \\i\\.

- y:

  Numeric vector of length \\J\\ containing observed pool outcomes.
  Allowed inputs are either binary indicators \\Z_j \in \\0,1\\\\ or
  quantitative Ct-like measurements encoded so that \\0\\ means
  undetected and \\0 \< y_j \< \texttt{ct\\threshold}\\ is treated as a
  positive pool.

- ct_threshold:

  Numeric scalar giving the positivity threshold applied when `y`
  contains Ct-like values. The default is `40`.

## Value

A list with components:

- candidates:

  Integer vector of potentially positive sample indices (1-indexed)

- negatives:

  Integer vector of definitely negative sample indices

- n_positive_pools:

  Integer; number of positive pools

## Algorithm

For each sample \\j \in \\1, \ldots, n\\\\:

\$\$\hat{x}\_j = \begin{cases} 0 \text{ (negative)} & \text{if } \exists
i : M\_{ij} = 1 \land y_i = 0 \\ 1 \text{ (candidate)} & \text{if }
\forall i : M\_{ij} = 1 \Rightarrow y_i = 1 \end{cases}\$\$

**In words**: A sample is marked negative if it appears in ANY negative
pool; it's a candidate (potentially positive) if ALL its pools are
positive.

## Theoretical Properties

1.  **No false negatives**: COMP never misses a true positive

2.  **May have false positives**: Negative samples in only positive
    pools are incorrectly marked as candidates

3.  **Exact for PP designs**: When \\k \leq k\_{max}\\, COMP is exact
    (no false positives) due to the intersection bound

## Exactness Theorem for PP Matrices

For a PP matrix with parameters \\(q, d, n_l)\\:

If there are at most \\k\_{max} = \lfloor(n_l-1)/(d-1)\rfloor\\ true
positives, COMP identifies them exactly.

**Proof**: Each negative sample shares at most \\d-1\\ pools with each
positive (intersection bound). With \\k\\ positives, a negative shares
at most \\k(d-1)\\ pools. If \\n_l \> k(d-1)\\, at least one pool
containing the negative is "clean" -\> COMP marks it negative.

## Time Complexity

\\O(m \times n)\\ where \\m\\ = pools, \\n\\ = samples.
