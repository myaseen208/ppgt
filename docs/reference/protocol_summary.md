# Summarize a Workflow-Layer Result

Summarize the output of
[`run_testing_workflow`](https://myaseen208.github.io/ppgt/reference/run_testing_workflow.md)
into a compact reporting object. This function belongs to the reporting
layer; it does not construct matrices, simulate outcomes, or run
decoders.

## Usage

``` r
protocol_summary(x)
```

## Arguments

- x:

  A workflow result object returned by
  [`run_testing_workflow`](https://myaseen208.github.io/ppgt/reference/run_testing_workflow.md).

## Value

A named list containing compact workflow counts, including the number of
pools, the number of individuals, the number of stage-1 non-negative
calls, the number of planned stage-2 retests, and the counts of final
positive, negative, and unresolved individuals.

## Details

Let \\\mathbf{M} \in \\0,1\\^{J \times N}\\ denote the stage-1 pooling
design matrix and let \\\mathbf{z}\\ denote the stage-1 pool outcomes. A
workflow result records stage-1 calls, optional stage-2 retests, and
final consolidated calls. The summary returned by `protocol_summary()`
is a reporting view of those stored objects. It does not re-run any
protocol logic.

## See also

[`run_testing_workflow`](https://myaseen208.github.io/ppgt/reference/run_testing_workflow.md),
[`simulate_group_testing`](https://myaseen208.github.io/ppgt/reference/simulate_group_testing.md),
[`PoolMatrix`](https://myaseen208.github.io/ppgt/reference/PoolMatrix.md)
