# Generate The Clinical P-BEST 2024 Pooling Matrix

Construct the pseudo-random balanced \\J \times N\\ pooling matrix used
for the 384-to-94 clinical P-BEST design reported by Zismanov et al.
(2024).

## Usage

``` r
pbest_clinical_matrix(N = 384L, J = 94L, seed = 42L)
```

## Arguments

- N:

  Integer scalar giving the total number of individuals. The default is
  `384L`. In the returned design this is the column dimension \\N\\ of
  \\\mathbf{M}\\.

- J:

  Integer scalar giving the total number of pools. The default is `94L`.
  In the returned design this is the row dimension \\J\\ of
  \\\mathbf{M}\\.

- seed:

  Integer scalar used to initialize the pseudo-random tie-breaking step.
  The default is `42L`. Different seeds generate different balanced
  realizations of the same construction heuristic.

## Value

A sparse binary matrix of class `dgCMatrix` with dimensions \\J \times
N\\. Under the default \\(N,J) = (384,94)\\ setting, each column sum is
seven and each row sum lies in \\\\28,29\\\\. The attached `design`
attribute is a named list with fields `type`, `N`, `J`, `seed`,
`pools_per_sample`, and `pool_size_range`.

## Details

This function targets the clinical design with \$\$N = 384, \qquad J =
94.\$\$ The implementation fixes the number of pools per individual at
\$\$w_i = \|\mathcal{J}\_i\| = r = 7\$\$ and therefore creates \$\$T =
Nr\$\$ total incidences. For the default parameter values, \$\$T = 384
\times 7 = 2688.\$\$ Distributing these incidences over \\J=94\\ pools
implies an average pool size of \\T/J \approx 28.6\\. The construction
therefore aims for a nearly balanced row-load profile with \$\$56 \text{
pools of size } 29 \quad \text{and} \quad 38 \text{ pools of size }
28.\$\$ The algorithm processes the individuals sequentially and assigns
each individual to the currently least-loaded pools, using pseudo-random
jitter to break ties. The output is thus a balanced heuristic
realization rather than a closed-form algebraic design. It is documented
as a package-specific heuristic constructor motivated by the reported
clinical matrix dimensions, not as a claim that the exact clinical
deployment matrix has been recovered.
