# Generate A Tapestry-Style Pooling Matrix

Construct a Tapestry-style pooling design in which each individual is
placed in exactly three pools and the resulting matrix is intended for
quantitative compressed-sensing reconstruction rather than binary COMP
decoding.

## Usage

``` r
tapestry_matrix(
  n,
  k = NULL,
  method = c("random", "kirkman"),
  prevalence = 0.01
)
```

## Arguments

- n:

  Integer scalar giving the total number of individuals. This is the
  column dimension \\N\\ of the returned pooling matrix and must satisfy
  \\N \ge 1\\.

- k:

  Optional integer scalar giving the expected number of positive
  individuals used to size the number of pools. If `NULL`, the function
  uses \\k = \max\\1, \lfloor N \cdot \texttt{prevalence}\rfloor\\\\.

- method:

  Character string specifying the construction rule: `"kirkman"` for a
  Kirkman-triple-inspired layout or `"random"` for a random triple
  assignment. The default is `"random"`.

- prevalence:

  Numeric scalar giving the expected prevalence used only when `k` is
  `NULL`. The default is `0.01`.

## Value

A named list with components:

- matrix:

  A sparse binary matrix of class `dgCMatrix` with dimensions \\J \times
  N\\

- m:

  The realized number of pools \\J\\

- n:

  The number of individuals \\N\\

- lambda_max:

  The target maximum column sum, fixed at 3

- method:

  The construction rule actually used

- design_type:

  "tapestry"

The matrix itself also carries a `design` attribute with fields `type`,
`n`, `m`, `lambda_max`, `k_expected`, and `method`.

## Details

Tapestry is a single-round design aimed at quantitative pooled
measurements and compressed-sensing-style reconstruction rather than
binary COMP decoding. In the package-wide notation, observed pool
outcomes are denoted by \\\mathbf{z}\\. This help page adopts a
decoder-local compressed-sensing notation, standard for the Tapestry
literature, in which \\\mathbf{A}\\ is the design matrix, \\\mathbf{x}\\
is the unknown sparse signal, \\\mathbf{y}\\ is the response vector, and
\\\mathbf{g}\\ is the measurement-noise vector. In that local notation,
\$\$\mathbf{y} = \mathbf{A}\mathbf{x} + \mathbf{g}.\$\$

This constructor places each individual in exactly three pools, so the
intended maximum column sum is \\\lambda\_{\max} = 3\\. The current
package implementation provides either a Kirkman-triple-inspired layout
or a random triple assignment. It returns only the constructed matrix
object and associated metadata; it does not implement a quantitative
decoder.

## Construction Methods

- `method = "kirkman"`:

  Uses the package's Kirkman-triple-inspired assignment path.

- `method = "random"`:

  Uses a random triple assignment while keeping each individual in
  exactly three pools.
