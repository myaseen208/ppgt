# Verify Polynomial Pools Matrix Properties

Check whether a matrix produced by
[`pp_matrix`](https://myaseen208.github.io/ppgt/reference/pp_matrix.md)
has the expected PP dimensions, row sizes, and column weights, and print
a concise validation summary.

## Usage

``` r
pp_verify(M)
```

## Arguments

- M:

  A binary pooling matrix, typically returned by
  [`pp_matrix`](https://myaseen208.github.io/ppgt/reference/pp_matrix.md).
  If the `"pp"` attribute is present, its stored parameters are included
  in the printed summary.

## Value

Invisibly returns a named list with:

- n_pools:

  Integer; the row dimension \\J\\

- n_samples:

  Integer; the column dimension \\N\\

- pool_size:

  Integer; the first observed row sum \\n_j\\

- sample_coverage:

  Integer; the first observed column sum \\w_i\\

- uniform_pools:

  Logical; `TRUE` if all row sums are equal

- uniform_coverage:

  Logical; `TRUE` if all column sums are equal

The function also prints a verification summary showing \\J\\, \\N\\,
row sums, column sums, compression, and density.

## Details

For a PP matrix \\\mathbf{M} \in \\0,1\\^{J \times N}\\, the key
structural quantities are \$\$n_j = \|\mathcal{P}\_j\| = \sum\_{i=1}^N
M\_{ji}\$\$ and \$\$w_i = \|\mathcal{J}\_i\| = \sum\_{j=1}^J
M\_{ji}.\$\$ In the untruncated PP design, every row sum is \\q^{d-1}\\
and every column sum is \\n_l\\. When \\N \< q^d\\, truncation preserves
the common column weight \\w_i = n_l\\ but may disturb row uniformity
near the truncation boundary. This function reports whether the realized
row and column sums are uniform, along with the empirical compression
ratio \$\$\frac{N}{J}.\$\$

## Relationship to pp_matrix and pp_design

- **[`pp_design`](https://myaseen208.github.io/ppgt/reference/pp_design.md)**:
  Planning - find valid configurations

- **[`pp_matrix`](https://myaseen208.github.io/ppgt/reference/pp_matrix.md)**:
  Construction - generate the matrix

- **`pp_verify`**: Validation - check the result

## Properties Checked

1.  **Uniform pool sizes**: All pools contain the same number of samples

2.  **Uniform sample coverage**: All samples appear in the same number
    of pools

3.  **Correct dimensions**: \\M = n_l \times q\\ pools, \\N \leq q^d\\
    samples

4.  **Stored parameters match**: q, d, nl, k_max
